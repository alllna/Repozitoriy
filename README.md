# Установка архива DentalClinicDoctorarchiv.zip

Данный архив содержит программу или данные для стоматологической клиники. Следуйте инструкции ниже, чтобы правильно установить содержимое на компьютер.

## Системные требования

- Операционная система: Windows 10/11, macOS, Linux
- Свободное место на диске: не менее 1 ГБ (рекомендуется)
- Программа для распаковки архивов: WinRAR, 7-Zip, встроенный архиватор ОС

## Инструкция по установке

### 1. Скачивание архива

Убедитесь, что файл `DentalClinicDoctorarchiv.zip` находится на вашем компьютере (например, в папке `Загрузки` или на рабочем столе).

### 2. Распаковка архива

**Способ 1 (с помощью проводника Windows / macOS):**
- Нажмите на файл правой кнопкой мыши.
- Выберите «Извлечь всё…» (Windows) или «Распаковать» (macOS).
- Укажите папку для распаковки (например, `C:\DentalClinic` или `Documents/DentalClinic`).
- Нажмите «Извлечь».

**Способ 2 (с помощью 7-Zip / WinRAR):**
- Нажмите правой кнопкой мыши на архив.
- Выберите `7-Zip` → `Распаковать в "DentalClinicDoctorarchiv\"`.
- Дождитесь завершения распаковки.

### 3. Установка программы 

В папке эксплуатационный пакет, есть установочный файл

1. Откройте распакованную папку.
2. Запустите установочный файл двойным щелчком.
3. Следуйте инструкциям мастера установки.


### 4. Запуск

После распаковки (и установки) запустите программу через ярлык на рабочем столе (если создан) или напрямую из папки с программой.


Если возникли сложности, обратитесь к разработчику ПО.

По установке мобильного приложения, а также получения архива проекта (мобильного приложения на Flutter), обратитесь к разработчику
